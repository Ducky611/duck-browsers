# Duck arcade and cinema

- Simplified the homepage to the Duck wordmark and a DuckDuckGo search field over the autumn pond.
- Added a dedicated game library and same-tab player with search, source filters, multiple versions, history, restart and fullscreen.
- Bundled the GN-Math, Chicken King’s Vault, Truffled and Ultimate Game Stash catalogs and compressed HTML game launch files. The player preserves source asset paths and uses a separate save area for each imported title.
- Added a full-film library and a shared source selector. The native video player remembers source preferences and carries the playback time between MP4 sources.
- Preserved the ten built-in games, trailer listings, password gate and Scramjet v2 browser.
